# Isar 데이터베이스에 채팅 기록 저장 및 조회 
## http 요청 
- TCP, UDP 방식 사용
- 프로토콜/호스트/포트/리소스 주소/쿼리

## REST API
- HTTP의 GET, POST, PUT, DELETE 메소드를 이용해서 통신

### GET 메소드 
- 서버로부터 데이터를 가져온다 

### POST 메소드 
- 데이터를 서버에 저장

### PUT 메소드 
- 데이터 업데이트

### DELETE 메소드
- 데이터 삭제

## Isar 데이터베이스 
- 데이터를 컬렉션 단위로 나눈다
- 컬렉션: 특정 자료형 객체를 모아 관리하는 개념
- @collection로 정의한다. 
- 컬렉션 정의하고 나서 빌드 러너 실행

# 파일 설명

- 모든 모듈에 공통으로 적용될 설정 관리
